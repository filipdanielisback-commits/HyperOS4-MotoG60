# hanoip device configuration workspace

This directory is reserved for original, reviewed device-specific configuration for the Motorola Moto G60 (hanoip).

No device tree is included yet. Do not add guessed BoardConfig values, partition sizes, fstab entries, init scripts, or proprietary file lists. First compare trusted upstream hanoip sources and confirm the exact target firmware and Android base.

See [research references](../../../docs/references.md) and [bring-up plan](../../../docs/bring-up-plan.md).
